# 前端约定：一致性与低资源占用

FanControlLX 使用原生 HTML/CSS/JavaScript；资源编译进 Rust 可执行文件。构建和运行不需要 npm，不使用外部 CDN、在线字体或图标服务。界面采用紧凑、中性的工具布局；没有安装 shadcn/ui，也不把相似外观称为使用了该组件库。

## 组件与依赖

- 优先复用浏览器的 `dialog`、`select`、`range`、表单、Grid/Flex、Pointer Events 和键盘行为，再考虑引入第三方库。已有依赖或原生控件能够正确表达时，不另写同类基础行为。
- 按钮、卡片、表单、状态标签使用 `static/style.css` 的颜色、字号、圆角、间距和动效变量。观看页与编辑页共用这些样式。
- 图标只使用 `static/icons.svg` 中的 Lucide 子集。来源固定为 Lucide 0.468.0，授权随 SVG 一并分发；增加图标从该版本的官方 SVG 获取，不临摹路径，不加载完整图标运行时。GPU 使用该版本的 `circuit-board` 图标。
- `static/theme.js` 在两页的 `<head>` 中先于样式同步加载，首次绘制前读取本机主题偏好，避免深色模式闪白。主题使用原生下拉框提供浅色、深色、跟随设备，默认跟随设备；监听系统主题及同源其他标签页的偏好变化，兼容已有浅色/深色偏好，存储不可用时仍可切换。`static/ui.js` 共享按变化写入 DOM 的辅助函数；`static/confirm.js` 使用原生 `<dialog>` 和 `method="dialog"` 表单统一确认操作。浏览器负责模态焦点和 Escape，取消按钮默认聚焦。离开网页的未保存提示继续使用浏览器的 `beforeunload`。
- `static/curve.js` 只处理共享预览与插值；`static/curve-editor.js` 只由编辑页加载。坐标轴和节点只在曲线、选择或尺寸变化时重建，实时读数只移动标记。编辑草稿与后台配置保持分离。
- 两页的风扇区域均可选择自动或 1–4 列，偏好保存在本机浏览器并在两页共用；窄屏限制为两列或一列以保证可读。卡片输出条用蓝色填充表示实际输出、橙色竖线表示目标输出；目标取未经过升降速限制的 `requested`，缺失时回退 `target`，显卡自动调速时隐藏该目标刻度。卡片曲线与编辑器只用一条蓝色竖线从横轴连接当前温度对应的曲线交点，不显示橙色点或实际输出位置。卡片预览没有独立边框或节点计数。
- 风扇卡片采用左右 12px、底部 8px 的内边距，收紧读数、输出条和控制区的间隔。编辑入口与设置、状态合并到底部一行；反馈仅在有内容时占用高度，取消状态和反馈区域预留的多行空白。观看页的温度刻度直接靠近卡片底边。
- 预览与编辑器的温度横轴固定为 20–100°C；鼠标、触摸、键盘和数值输入均将新增或修改节点限制在此范围。旧配置仍可读取，超出范围的曲线按边界插值裁切显示，不因页面浏览改写后台配置。
- 当前排序已有鼠标、触摸、键盘、取消和持久化回归。暂时保留现有实现；如果后续扩展到跨区拖放或更多排序类型，再评估 dnd-kit 与维护成本。
- 不为当前功能引入 React、Motion、Zustand 或可调整分栏。以后选型应以具体需求、按需构建体积、实测浏览器开销和维护收益为依据，不能仅因规范列出了库名就全部安装。

## 更新与动画

- 编辑页导航使用 `#control`、`#devices`、`#sensors`、`#diagnostics`，刷新、前进和后退保持对应页面；文档标题跟随导航。首次连接前禁用依赖服务的操作。
- 卡片上的即时保存结束后恢复原控件的键盘焦点；用户已经移到其他控件或弹窗时不抢焦点。曲线节点数值更新保留输入框，支持连续 Tab 编辑；Ctrl/Cmd+S 先提交当前输入，并遵守最上层确认窗口。
- 曲线、风扇设置和离线配置在保存期间锁定表单并显示“正在保存”；曲线图也停止接受修改。失败时保留草稿并恢复编辑；断线时明确提示草稿保留，恢复连接后重新允许保存。弹窗使用可访问的标题关联。
- 两页在风扇区统一显示实际输出与目标输出的图例。手机端适度扩大模式选择、控制开关、拖动入口和关闭按钮；宽屏保持卡片原有紧凑内边距。卡片焦点和保护运行有明确边框反馈。

- 可见页面每次轮询完成后约 1.5 秒再次刷新；隐藏时停止，恢复可见时立即刷新。后台采样和硬件保护独立运行。
- 观看页只请求 `/api/view`，不加载编辑器、提交控制请求或发送设备发现心跳。
- `/api/view` 首次返回最近 80 次 CPU/GPU 温度采样，之后按启动/配置版本与采样序号增量获取历史和实时读数；配置变化、服务重启或超过历史窗口后自动补全。观看页与编辑页复用趋势绘制，保留 SVG 路径节点，只更新路径属性；空缺采样断开曲线，断线时保留历史但清除实时位置标记。
- 风扇读数变化只更新文本、输出条和 SVG 标记，保留卡片与曲线节点。相同文本、属性和静态内容不重复写入。每张卡片只保留当前结构签名，不累积历史 DOM。
- 编辑页的曲线库和 GPU 来源标签使用一份共享结构签名，配置对象或来源变化时才重新计算；每张卡片只保存自身配置与运行条件。数字和时间的本地化格式器跨刷新复用。
- 输出条直接显示最新值，不对高频读数做宽度动画。按钮、开关和弹窗只在交互时做短暂反馈；遵守 `prefers-reduced-motion`，不持续旋转图标或启用装饰性循环动画，不使用背景模糊。

## 验证

`tests/browser-smoke.mjs` 检查观看/编辑分离、隐藏页停止轮询、读数更新时保留图表节点、编辑焦点、确认取消/提交、曲线、拖拽以及桌面/手机布局；通过暂停两页的主模块验证首帧配色，并覆盖主题跟随设备、手动覆盖、偏好持久化及存储不可用时的切换。另覆盖导航历史和刷新、自动保存焦点、节点 Tab 顺序、Ctrl/Cmd+S 提交未失焦的数值、慢请求期间禁止重复保存和图形编辑、保存失败/断线后的草稿恢复，以及 1920px 下的卡片间距。

浏览器性能脚本不安装依赖，默认不写入演示配置。只允许对演示实例运行：

```bash
./target/release/fancontrollx --demo --service --port 18091 --data-dir /tmp/fancontrollx-perf-demo
# 另一终端；输出目录需事先存在
CHROME_BIN=/path/to/chrome node tests/benchmark_frontend.mjs \
  http://127.0.0.1:18091 test-results/frontend.json
```

脚本在无头 Chromium、关闭 GPU、1440×1100 下，对观看页、控制页、新建共享曲线窗口各测约 6.5 秒。固定配置，每次轮询模拟读数与 80 条历史变化，以隔离渲染工作。记录渲染线程任务耗时、布局次数、图表 DOM 变化和 GC 后 JS 堆。它不测整个浏览器进程 RSS、真实 GPU 成本或耗电，也不能把结果直接解释为整机 CPU 降幅。DOM 观察器和测试工具本身有开销。

增加第三个参数 `--large` 会把该演示实例替换为 64 路离线风扇、128 条 32 节点曲线，用于检查配置规模增长后的开销；仅用于可丢弃的演示目录。浏览器测试使用临时配置目录、普通密码存储并关闭首次运行提示和后台更新，避免依赖桌面密码库。
